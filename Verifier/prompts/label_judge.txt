{question_text}

{numbered_gt_claims}

TASK 1 — FORWARD (precision side). For EACH response claim, label it against the GT and list which GT claim(s) it supports:
  "addressed"           = states a fact that IS in the GT;
  "partially_addressed" = right direction but missing specifics (a number, a range, a strength grade, a named agent, a condition);
  EVIDENCE PRECISION: when the GT claim carries a confidence interval, a sample size, or the study design behind a figure, and the response gives only the point estimate, that is PARTIAL, not full support -- matching the figure alone is not enough, because how well established the figure is has been dropped.
  "wrong"               = contradicts a GT fact (opposite action/direction, or a different value for the same quantity);
  "extra"               = factually correct but NOT in the GT.
  matching_gt_indices   = the GT index/indices this claim supports; [] for "wrong" and "extra".

TASK 2 — BACKWARD (recall side). For EACH GT claim, judge how fully the RESPONSE states it:

  "partial" = the response states part of it — right direction or main point, but a specific is missing, or it names a DIFFERENT agent for the same role;
  "missing" = the response does not state it at all.
  Judge the clinical MEANING, not the wording.
