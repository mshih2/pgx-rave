## What to write

A vignette that states age, the clinical situation, the genotype as a test report gives it (use
one of the example diplotypes; for a row keyed on two genes, give both genes' results), the drug
and the population, and asks for what this row answers: the recommendation and the facets the row
carries (implication, strength, dosing, alternatives, comments). Name the gene, alleles and drug
exactly as CPIC writes them.

If the row cannot support a sensible clinical question, say so.

## Output

Return JSON only:

{"question": "...",
 "asks": ["1. ...", "2. ..."],
 "facets": ["facet names the question raises"],
 "answer_direction": "change | no_change | mixed",
 "population": "...",
 "skip": null}

or, when no question fits: {"skip": "why, in one sentence"}
